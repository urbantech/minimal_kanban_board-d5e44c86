# Product Requirements Document

## Project Overview
**Name:** minimal_kanban_board
**Type:** web_application
**Created:** 2026-11-01T18:27:46.124819

## Description
Build a minimal kanban board. User authentication (email/password). Create a card, move a card between three fixed columns (todo/doing/done), delete a card. List all cards for the logged-in user. (Type: web_app)

## Features
- authentication
- card_management
- responsive_design

## User Stories
### User Authentication
As a user, I want to create an account and log in so that I can access personalized features.

**Acceptance Criteria:** User can register, login, logout, and reset password

## Business Logic
- create_card
- move_card
- delete_card
- list_user_cards
